
# Rollback Evidence

## Objective
Document the procedure for recovering the security event classification dataset if an incorrect version is uploaded.

## Rollback Procedure
1. Identify the incorrect dataset or documentation change.
2. Locate the last verified version in GitHub history or Google Sheets version history.
3. Restore the previous verified version.
4. Upload the corrected CSV file to GitHub if required.
5. Verify that the dataset contains all expected events, classifications, and reasons.

## Verification Checklist
- [ ] Previous version identified.
- [ ] Rollback performed.
- [ ] Restored dataset checked.
- [ ] Repository verified.
